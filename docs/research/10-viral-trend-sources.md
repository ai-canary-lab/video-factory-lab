### 6. YouTube Shorts

- **官方趋势榜单**：**没有专门的 Shorts 官方趋势榜单**。原有的 YouTube Trending（热门）标签页已于 **2025 年 7 月 22 日正式下线**（⚠️ 来自媒体报道与百科条目）。
- **替代入口**（⚠️）：
  - YouTube Charts：继续运营，覆盖热门音乐视频、热门播客、电影预告，计划扩展到更多品类。
  - Explore（探索）标签页、游戏探索页：按品类发现热门内容。
  - YouTube Studio「灵感」标签页（Inspiration tab）：面向创作者，展示受众兴趣与新兴话题，需登录创作者账号。
- **免费 API**：YouTube Data API v3 的 `videos.list?chart=mostPopular` 可免费拉取各地区热门视频（免费 API Key，每日 10k 配额），配合时长过滤可筛出 Shorts（⚠️ 来自开发者文档与第三方教程）。
- **是否免费**：Charts / Explore 免费浏览；API 免费（需申请 Key）。
- **对"找可复刻爆款"的价值**：中低。没有 Shorts 专属官方榜，监控要靠第三方（SocialBlade、NoxInfluencer 免费工具）或自建 API 抓取。
