## 可复用的经验（已提炼进 SOP）

1. **资产库先行**：长片质量不取决于单镜头抽卡运气，而取决于开工前是否沉淀了
   人物/场景/道具设定卡。剧本定稿后、分镜前插入"资产冻结"工序，后续镜头只能引用库内资产 ID。
2. **转场单独 QC 门控**：接缝两侧亮度/色温连续性、相邻镜景别差、锚点文本一致性比对——
   "个别转场穿帮"应在管线内被拦截，而不是留给观众发现。
3. **Agent 编排 + 多模型渲染后端**：产品化的是故事理解、资产管理、一致性、对口型这些
   "管线层"能力；渲染层做成可插拔（Seedance/可灵/Vidu 按镜头类型路由）。模型每季度换代，管线层才是长期资产。
4. **为筛选预留预算**：AI 长片的真实瓶颈不在生成而在筛选（参考《霍去病》1700 张选 95 张），
   按终版镜头数 × 10–15 倍生成量估算；废卡标注原因反哺 prompt 模板库。
5. **配音与对口型进主流程**：台词定稿 → 干声 → 唇同步 → 混音，顺序不可打乱，逐镜验收。
