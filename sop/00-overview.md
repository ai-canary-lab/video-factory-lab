# SOP 总览：阶段地图与人机分工

> 本仓库是**面向 agent** 的：用户提供创意，agent 全权执行。
> 用户永远只做两件事：**给创意**、**做确认**。其余一切都是 agent 的活。

## 阶段地图

```
Phase 0 立项      用户一句话创意 → agent 引导式提问 → project-brief.md
Phase 1 剧本      agent 共创起草 / 或推荐外部工具 → 用户带回 → 冻结剧本
Phase 2 角色设计   用户描述 → agent 生成三视图九宫格 → 用户点选 → 冻结角色卡
Phase 3 场景设计   同上 → 冻结场景卡
Phase 4 分镜      agent 按剧本拆镜 → 用户确认每镜动作 → 冻结分镜表
Phase 5 生成      agent 批量生成（用户可离场）→ agent 抽帧质检 → 用户终审
Phase 6 配音      agent TTS → 用户试听确认音色
Phase 7 后期      agent 拼接/字幕/输出 → 用户验收成片
```

详见：前期 `sop/01-preproduction.md`，制作 `sop/02-production.md`，后期 `sop/03-post.md`。
门禁清单：`sop/gates.md`。

## 人机分工总表

| 阶段 | 用户（创意决策） | Agent（全权执行） |
|---|---|---|
| 0 立项 | 一句话创意、回答 5–7 个选择题 | 提问、整理、输出立项书 |
| 1 剧本 | 讲故事、改稿、拍板 | 起草剧本 / 推荐外部写作工具并接管回传稿 |
| 2–3 角色/场景 | 文字描述或丢参考图、九宫格点选 | 生成候选、冻结角色卡/场景卡 |
| 4 分镜 | 确认每镜头的动作（一句话） | 拆镜、组装 prompt、冻结分镜表 |
| 5 生成 | 终审关键帧（只看通过质检的） | 批量生成、多 take、抽帧质检、打回重生 |
| 6 配音 | 试听、选音色 | 生成配音、时间轴对齐 |
| 7 后期 | 验收成片、提修改意见 | 拼接、字幕、调色、输出、归档 |

## 核心协作原则

1. **用户不写长文档**：超过一屏的文档工作，agent 起草或推荐外部工具，用户只改只选。
2. **用户不做重复劳动**：批量、拼接、格式转换全部脚本化。
3. **用户不猜**：每个决策点 agent 给出带推荐的选项。
4. **可复现**：每次生成记录模型/prompt/seed/参考图版本，没有记录=没发生过。
