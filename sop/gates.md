# 门禁清单 Gates

> agent 每完成一个阶段，对照打勾。全绿才能进入下一阶段。

## Phase 0 立项 → 1

- [ ] `projects/<项目>/brief.md` 存在
- [ ] 产品线明确（漫剧 / 营销视频）
- [ ] 时长、观众、风格三要素已确认

## Phase 1 剧本 → 2

- [ ] `script-v1.0.md` 已冻结（版本号已打）
- [ ] 对白/旁白时长精确到秒，总时长符合立项书
- [ ] 用户亲口确认"剧本定了"

## Phase 2/3 角色/场景 → 4

- [ ] 每个角色/场景都有冻结的卡（含定稿图、seed、voiceId）
- [ ] 用户已点选确认每一张定稿图

## Phase 4 分镜 → 5

- [ ] `shots.yaml` 已冻结，每个镜头只有一个动作
- [ ] 分镜静帧已过用户评审（如采用 storyboard-first）

## Phase 5 生成 → 6

- [ ] 每个镜头 ≥1 个可用 take，命名规范
- [ ] 三处质检点记录完整（静帧/抽帧/拼接）
- [ ] 用户已终审所有镜头（"通过/换一个"二选一完成）

## Phase 6 配音 → 7

- [ ] 音色与角色卡 voiceId 一致，用户已试听确认
- [ ] 配音时间轴与镜头对齐

## Phase 7 后期 → 交付

- [ ] AI 标识角标已加，备案/平台合规已确认
- [ ] `runs/<时间>/` 记录完整（模型/prompt/seed 可复现）
- [ ] 用户验收通过
