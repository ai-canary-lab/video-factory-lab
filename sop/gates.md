# 门禁清单 Gates

> 先跑 `scripts/gate_check.py --phase N --project <项目>`（规划中），脚本全绿再人工确认剩余项。
> `[自动]` = 脚本可校验，`[人工]` = 必须用户明确确认（"继续"/空回复/表情不算确认）。

## Phase 0 立项 → 1

- [ ] [自动] `projects/<项目>/brief.md` 存在
- [ ] [人工] 产品线明确（漫剧 / 营销视频）
- [ ] [人工] 时长、观众、风格三要素已确认

## Phase 1 剧本 → 2

- [ ] [自动] `script-v1.0.md` 已冻结（版本号已打）
- [ ] [自动] 对白/旁白时长精确到秒，总时长符合立项书
- [ ] [人工] 用户亲口确认"剧本定了"

## Phase 2/3 角色/场景 → 4

- [ ] [自动] 每个角色/场景都有冻结的卡（含定稿图、seed、voiceId、连续性锁）
- [ ] [人工] 用户已点选确认每一张定稿图

## Phase 4 分镜 → 5

- [ ] [自动] `shots.yaml` 已冻结，每个镜头只有一个动作
- [ ] [自动] 本镜 prompt 包含其角色全部连续性锁短语（机检）
- [ ] [人工] 分镜静帧已过用户评审（如采用 storyboard-first）
- [ ] [人工] **灰样已过**：零成本预演（镜头顺序 + 对白时间轴 + 关键静帧），
      用户确认故事节奏成立，再进入烧钱的视频生成

## Phase 5 生成 → 6

- [ ] [自动] 每个镜头 ≥1 个可用 take，命名规范
- [ ] [自动] 三处质检点记录完整（静帧/抽帧/拼接）
- [ ] [人工] 用户已终审所有镜头（"通过/换一个"二选一完成）

## Phase 6 配音 → 7

- [ ] [自动] 音色与角色卡 voiceId 一致
- [ ] [人工] 用户已试听确认
- [ ] [自动] 配音时间轴与镜头对齐

## Phase 7 后期 → 交付

- [ ] [自动] AI 标识角标已加
- [ ] [人工] 备案/平台合规已确认
- [ ] [自动] `runs/<时间>/` 记录完整（模型/prompt/seed 可复现）
- [ ] [人工] 用户验收通过
