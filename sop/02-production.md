# SOP 制作：生图 → 视频 → 质检

> 制作阶段用户可以离场。agent 批量跑，质检通过的才拿给用户终审。

## 生图定稿（如分镜阶段未做）

- 按冻结的角色卡/场景卡批量生图，人工筛选定稿图。
- 规则：同一角色/场景的所有镜头共用同一张（组）定稿图做输入。

## 视频生成

- 输入：定稿图 + 分镜 prompt（图生视频优先于纯文生视频，一致性高一个量级）。
- 每个镜头生成 **3 个 take**，命名 `EP01_SC03_SH02_take{n}.mp4`。
- agent 异步批量跑，写 `runs/<时间>/gen.log`（模型/prompt/seed 全记录）。

## 三处质检点（来自调研的最佳实践）

1. **分镜静帧评审**：转视频前先审静帧，穿帮在最便宜的环节拦掉。
2. **生成后抽帧**：人脸、服装、场景三要素抽检，不合格打回重生，不进入终审。
3. **拼接处检查**：镜头衔接处的漂移/跳变，留 0.5 秒交叉淡化余量。

## 给用户的终审

- 用户只看**通过质检的候选**，每个镜头 agent 先推荐 1 个最佳 take，
  用户只做"通过 / 换一个"二选一。
- 用户不看废片，不参与打回重生的循环 —— 那是 agent 的体力活。
