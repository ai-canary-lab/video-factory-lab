# video-factory-lab 🎬

AI 视频生产工厂：从调研、剧本、分镜到成片的完整流水线知识库与工具链。

> 核心原则：像好莱坞工业一样做 AI 视频 —— 前期钉死（剧本 / 分镜 / 角色设定集），
> 后期让 AI 只做执行，不做自由发挥。

## 仓库结构

| 目录 | 说明 |
|---|---|
| `docs/research/` | 市场与技术调研（知识库，持续更新） |
| `docs/pipeline/` | 流水线各阶段规范（准入/准出标准） |
| `prompts/templates/` | Prompt 模板：角色卡、场景卡、分镜模板 |
| `scripts/` | 流水线脚本：批量生成、拼接、字幕、质检 |
| `assets/` | 素材占位（成片素材不进仓库，大文件走 release/对象存储） |

1. **漫剧**（AI comic drama）：连载向，角色一致性是生死线
2. **产品营销视频**：单条向，卖点可视化 + 节奏是关键
