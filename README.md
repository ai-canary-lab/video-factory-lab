# video-factory-lab 🎬

**面向 AI agent 的视频创作 SOP + 知识库。**

用户提供创意，agent 全权执行：从剧本、分镜、角色设计到成片，
agent 按 `sop/` 手册带领用户走完整个流程，用户只做创意决策和确认。

> 核心原则：像好莱坞工业一样做 AI 视频 —— 前期钉死（剧本 / 分镜 / 角色设定集），
> 后期让 AI 只做执行，不做自由发挥。

## 从哪里开始

- **你是 agent**：先读 [`AGENT.md`](AGENT.md)，再看 [`INDEX.md`](INDEX.md) 找知识库地图。
- **你是用户**：直接跟你的 agent 说"我想做个视频"，它会按 SOP 引导你。

## 仓库结构

| 目录 | 说明 |
|---|---|
| `AGENT.md` | agent 工作手册（角色、工作循环、铁律） |
| `INDEX.md` | 知识库总索引（防腐烂维护规则） |
| `sop/` | 分阶段 SOP + 门禁清单 |
| `docs/research/` | 市场与技术调研（持续更新） |
| `docs/cases/` | 标杆案例结构化拆解 |
| `prompts/templates/` | 角色卡、场景卡、分镜 prompt 模板 |
| `scripts/` | 流水线脚本（批量生成、质检、拼接、字幕） |
| `projects/` | 具体项目的产出物（每个项目一个目录） |
